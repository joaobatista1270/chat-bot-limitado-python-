#  Chatbot Limitado

Um chatbot limitado a 21 palavras funcionais.

## 💬 Como interagir
* **O que faz?** Interage contigo através de comandos básicos.
* **Como ver as palavras?** Digita `"barra conversa"` para ver as palavras funcionais disponíveis.
